## [0.1.4] - 2026-08-16
- **Фикс падения UI при выборе украинского** (баг из 0.1.2/0.1.3).
  - Симптом: `RuntimeError: libshiboken: Internal C++ object (QComboBox) already
    deleted` при переключении языка на окне входа; все виджеты формы «разваливались».
  - Причина: `_build_form()` пересобирал форму через `QFormLayout.removeRow`,
    который **удаляет** виджеты строки (layout владеет ими), а код затем
    переиспользовал старые ссылки (`self.lang_combo` и т.п.) - объект уже мёртв.
  - Решение: форма строится один раз; метки вынесены в `self._labels` и при смене
    языка обновляются через `_retranslate()` (тексты меток, заголовок окна,
    комбо тем, тексты комбо «Режим»). Никаких removeRow/takeRow - виджеты живут.
- Обновлён `_TEMP/smoke_test.py`: новый блок-регрессия «смена языка не роняет
  форму» (ru→ua→en→ru, проверка строк, текстов меток, живости виджетов).
